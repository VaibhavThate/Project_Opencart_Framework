#  Playwright Python Automation Framework (Opencart)

This is a scalable UI automation framework built using Python and Playwright with CI/CD integration using Jenkins.

---

##  Tech Stack

- Python
- Playwright
- Pytest
- Jenkins
- Allure Reports
- GitHub (SCM)
- Pytest-xdist (Parallel Execution)

---

##  Project Structure

Project_Opencart_Framework/
│
├── test_cases/          # Test scripts

├── pages/               # Page Object Model classes

├── utilities/           # Helper utilities

├── test_data/           # Test data (JSON/CSV/Excel)

├── reports/             # Generated reports

├── allure-report/       # Allure report output

├── conftest.py          # Fixtures setup

├── config.py            # Configurations

├── pytest.ini           # Pytest settings

├── Jenkinsfile          # CI/CD pipeline

├── requirement.txt      # Dependencies


└── README.md

---

##  Features

- Page Object Model (POM) design
- Data-driven testing (JSON, CSV, Excel)
- Parallel execution using pytest-xdist
- Retry mechanism for flaky tests
- HTML reporting
- Allure reporting
- Screenshot & trace on failure
- CI/CD integration with Jenkins
- GitHub integration

---

##  How to Run Locally
